# Dasmoto's Arts & Crafts

A simple website for a fictional arts and crafts store, built for the Codecademy Full-Stack Engineer career path (Developing Websites Locally / Developing with CSS).

## About The Project

The project brief (from the course assignment): build a simple website for a fictional arts and crafts store on your own computer, with a sensible folder structure, an HTML file and a CSS file, following a design spec like one a freelance web developer would receive.

### Built With

- HTML5
- CSS3
